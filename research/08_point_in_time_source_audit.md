# 08｜Point-in-time 研究资料审计及投资委员会证据标准

## 1. 已处理的重大错误

**AUD-010（严重 / 已修复）**：旧版文档把宇树科技写为未上市公司，并称无法获取 2025/2026 真实财务。本轮从 [上海证券交易所官方页面](https://www.sse.com.cn/star/market/stocklist/info/company/index.shtml?COMPANY_CODE=688836) 确认 **2026-08-19 已上市，股票代码 688836**。新增 [宇树真实投资备忘录](09_unitree_688836_real_public_countercase.md)，数据/反向估值独立运行；旧版虚构机器人经营模型只做教学示例，不得假装为宇树真实估值。

**AUD-001（严重 / 已修复）**：旧版 IFR humanoid 2025 销量资料链接误指向无关声明。修订到 [IFR 全球专业服务机器人 2026 报告](https://ifr.org/ifr-press-releases/global-sales-of-professional-service-robots-surge-24-percent)。请注意 IFR 的全尺寸专业/商业与不同研究机构的全部机器人出货不是相同口径。

**AUD-002/003/004（已修复）**：修订 NVIDIA、CoreWeave 第一手链接，UBTECH 文件指向完整中期报表镜像并标明未审计，来源细节见 [审计登记册](../data/source_audit_20261027.csv)。

**AUD-005/006（严格管控）**：正式市场定价必须区分交易所时区。VRT 本稿使用已确认 **NYSE 2026-10-23 完整收盘价**；上海科创板 2026-10-26 在截点前已收盘，可使用 10-26 宇树收盘；**VRT 2026-10-28 Q3 尚未发布，不能提前使用**。

**AUD-007/008（严格管控）**：禁止把经营现金流直接等于利润、假设的退出倍数当市场可比交易、旧虚构算力企业 Bear/Base/Bull 当真实 VRT 估值。两套真实股票分析模型与模拟模型严格分离。

## 2. 四级证据和可信度

| 等级 | 定义 | 投资用途 |
|---|---|---|
| A | SSE/SEC 已生效公开文件、公司正式投资者公告、已审计或标记未经审计财务 | 可作历史财务基础，注意会计口径与日期 |
| B | 完整且可复核的历史收盘行情/财经信息披露镜像 | 可作报价复核，需尽可能二次确认 |
| C | 研究机构对其特定定义市场的估计、行业协会预测 | 用于背景与假设区间，不能代替订单 |
| D | 分析师 FY2027 假设、退出倍数或假设的上市公司经济性 | 只可做压力与情景决策讨论，**绝不能称实际事实** |

所有材料保持日期、币种、期间、财务/非GAAP、分部与整体收入定义。中美股市不能把尚未结束的交易日当收盘。

## 3. 真实证券估值中不能混用的数据

- 宇树 IPO **2026-08-19 后股本**与 IPO 前 H1 资产负债表跨事件：仅推股权市场价值，不伪造完整上市后企业 EV。
- 宇树 2026 H1 **扣非**财务与 2025 H1 因股份支付导致的同比归母利润波动：须同时看同比扣非与经营现金流。
- NVIDIA **FY2027 Q2**（结束2026年7月）不等于财务自然年 2027 Q2。
- Vertiv **GAAP 营业利润**、**管理层调整后营业利润**与 **EBITDA** 三者不能替换。
- VRT 未确认的 Oct26 closing price不得按Oct26已结束价格计算 NYSE 市值。
- IFR 全尺寸专业商用的 2025 数据与 Counterpoint H1 2026 全口径 shipments不构成同定义增长率。

## 4. 仍未解决的实质性尽调

IC 公共版本可以讨论可投资标的，但**不能**声称已获取：

1. VRT 10月28日新披露的第三季度财报与其 Q4 修正后全年指引（研究日之后）。
2. 宇树 IPO 后截至 2026Q3 的完整现金净债务表、后续限售股解禁日期及逐产品实际利润。
3. 任何非公开客户、供应商、工厂研发或售后服务台账，以及真实独立机器人工作任务测试。
4. 真实目标公司的未披露订单履约、存货信用质量、长期融资与债务 covenant。
5. 市场的同日有效可比公司 EV/利润倍数完整数据（要同时考虑流通、会计、现金/债务与交易日差异）。

这些尚未完成内容必须进入 IC 中的**带负责人和截止条件的下一轮清单**，不得标记已尽调通过。

## 5. 可复算准入流程（真实案例）

1. 封存某一准确市值截点的收盘价、总股本；上市后资本结构调整单独记录。
2. 严格提取第一手法定财务，保留财报发布日期、会计报告期、是否审计、币种。
3. 用纯函数计算市场权益市值、可验证债务净额桥接、历史比率（没有新股发现金额就不计算）。
4. 将 FY2027 假设与实际 2025/2026 数据分开记录（JSON/CSV）。
5. 把 Bear/Base/Bull 清楚标记为情景，提供负面结果与反论证。
6. 审计 GitHub CI、本地运行、数据血缘链和 HTML 生成内容。
7. IC 开会提出**明确决议建议、阻断条件、数据缺口和复核日期**；不能给没有授权的投资人自动下单。
